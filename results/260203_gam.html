Method Comparison

  • Ran GAM models on both the diabetes and Boston housing datasets.

GAM fit

mgcv package

mgcv::gam(y ~ age + bmi + bp + s1 + s2 + s3 + s4 + s5 + s6 + 
            s(age, bs = "tp", m = 1, k = 10) + 
            s(bmi, bs = "tp", m = 1, k = 10) + 
            ... + 
            s(s6, bs = "tp", m = 1, k = 10), 
            data = gam_data, method = "REML")
  • Setting m = 1 applies a first-derivative penalty

gam package

gam::gam(y ~ age + bmi + bp + s1 + s2 + s3 + s4 + s5 + s6 +
            s(age) + s(bmi) + s(bp) + s(s1) + s(s2) + 
            s(s3) + s(s4) + s(s5) + s(s6),
            data = gam_data)
  • Explicitly decomposes each predictor into a parametric (linear) part and a nonparametric (smooth) part.
  • Linear effects are fitted via weighted least squares inside the backfitting algorithm.
  • Provides separate ANOVA tables for linear effects and departures from linearity.
