Prior Predictive Calibration for GP Magnitude (δ) and Length-scale (λ)

1 Goal

In my GP model, the nonlinear component is parameterized as

\[ f \sim \mathcal{N}\!\left(0,\ \sigma^2 \delta^2 K_{\lambda}\right), \qquad y = \mu + f + \varepsilon,\quad \varepsilon \sim \mathcal{N}(0,\sigma^2 I). \]

Thus the GP marginal s.d. is \(\sigma_f=\sigma\delta\) and the noise s.d. is \(\sigma_n=\sigma\), so

\[ \frac{\sigma_f}{\sigma_n} = \delta. \]

This report uses prior predictive calibration to translate the qualitative statement “\(\delta=1\) small, \(\delta=2\) medium, \(\delta=3\) large” into an operational statement about the typical amplitude of prior GP draws over a finite domain (with inputs scaled to \([0,1]\)).

Key point: \(\delta\) sets amplitude relative to noise, while \(\lambda\) controls how that amplitude is expressed across \([0,1]\) (wiggly vs. smooth).

2 Setup

We assume:

  • 1D grid \(x \in [0,1]\) (can be generalized to multi-D later).

  • Squared exponential kernel: \[ k(x,x') = \exp\left(-\frac{(x-x')^2}{2\lambda^2}\right). \]

  • We simulate functions from the prior and summarize:

    • sd_over_sigma \(=\mathrm{sd}(f(x))/\sigma\)
    • range_over_sigma \(=(\max f - \min f)/\sigma\)

These are interpretable as “in units of noise s.d.”.

3 Code

library(MASS)
library(dplyr)
library(tidyr)
library(ggplot2)

# Squared-exponential kernel on 1D grid
k_se <- function(x, lambda) {
  D2 <- outer(x, x, "-")^2
  exp(- D2 / (2 * lambda^2))
}

# Draw f ~ N(0, sigma^2 * delta^2 * K_lambda)
draw_f_prior <- function(x, lambda, sigma = 1, delta = 1, jitter = 1e-10) {
  K <- k_se(x, lambda)
  K <- K + diag(jitter, nrow(K))
  Sigma_f <- (sigma^2) * (delta^2) * K
  as.numeric(mvrnorm(n = 1, mu = rep(0, length(x)), Sigma = Sigma_f))
}

summarize_effect <- function(f, sigma = 1) {
  c(
    sd_over_sigma    = sd(f) / sigma,
    range_over_sigma = diff(range(f)) / sigma
  )
}

calibrate_delta <- function(
  deltas = c(1, 2, 3),
  lambdas = c(0.1, 0.3, 0.7),
  n_grid = 200,
  n_draw = 2000,
  sigma = 1,
  seed = 1
) {
  set.seed(seed)
  x <- seq(0, 1, length.out = n_grid)

  out <- list()
  idx <- 1

  for (lambda in lambdas) {
    for (delta in deltas) {

      stats_mat <- matrix(NA_real_, nrow = n_draw, ncol = 2)
      colnames(stats_mat) <- c("sd_over_sigma", "range_over_sigma")

      for (b in 1:n_draw) {
        f <- draw_f_prior(x, lambda = lambda, sigma = sigma, delta = delta)
        stats_mat[b, ] <- summarize_effect(f, sigma = sigma)
      }

      qs <- apply(stats_mat, 2, quantile, probs = c(0.1, 0.5, 0.9))
      out[[idx]] <- data.frame(
        lambda = lambda,
        delta = delta,
        metric = colnames(stats_mat),
        q10 = qs[1, ],
        q50 = qs[2, ],
        q90 = qs[3, ],
        row.names = NULL
      )
      idx <- idx + 1
    }
  }
  bind_rows(out)
}

res <- calibrate_delta(
  deltas = c(1, 2, 3),
  lambdas = c(0.1, 0.3, 0.7),
  n_grid = 200,
  n_draw = 2000,
  sigma = 1,
  seed = 123
)

5 Discussion

  1. \(\delta\) is scale-free in \(y\). Since \(\frac{\sigma_f}{\sigma_n} = \delta\), not scaling \(y\) does not hinder interpretation of \(\delta\).
  2. Small/medium/large depends on \(\lambda\) regime. The calibration becomes concrete once we pick a reference \(\lambda\) (e.g. \(\lambda = 1/3\) in simulations).
  3. Proposed paper sentence (draft):
    “With inputs scaled to \([0,1]\) and moderate smoothness (\(\lambda = 0.3\)), prior GP draws have median peak-to-peak ranges of approximately \((r_1, r_2, r_3)\) noise standard deviations for \(\delta = 1, 2, 3\), respectively; we therefore treat \(\delta \approx 1, 2, 3\) as small/medium/large nonlinear magnitudes under this standardization.”
  4. Next step (if needed): repeat the same calibration but integrate over the \(\lambda\) prior (instead of conditioning on a grid of \(\lambda\) values), so the calibration matches the actual prior used in the model.

6 Optional extension: integrate over a λ prior (marginal calibration)

If we have a prior for λ, we can sample λ from that prior and repeat the same summaries to get an unconditional calibration.

r_lambda <- function(n) 1 / rgamma(n, shape = 3, rate = 0.8)

calibrate_delta_marginal_lambda <- function(
  deltas = c(1,2,3),
  n_grid = 200,
  n_draw = 2000,
  sigma = 1,
  seed = 1
) {
  set.seed(seed)
  x <- seq(0, 1, length.out = n_grid)

  out <- list()
  idx <- 1

  for (delta in deltas) {
    stats_mat <- matrix(NA_real_, nrow = n_draw, ncol = 2)
    colnames(stats_mat) <- c("sd_over_sigma", "range_over_sigma")

    lambdas <- r_lambda(n_draw)

    for (b in 1:n_draw) {
      f <- draw_f_prior(x, lambda = lambdas[b], sigma = sigma, delta = delta)
      stats_mat[b, ] <- summarize_effect(f, sigma = sigma)
    }

    qs <- apply(stats_mat, 2, quantile, probs = c(0.1, 0.5, 0.9))
    out[[idx]] <- data.frame(
      delta = delta,
      metric = colnames(stats_mat),
      q10 = qs[1, ],
      q50 = qs[2, ],
      q90 = qs[3, ],
      row.names = NULL
    )
    idx <- idx + 1
  }

  bind_rows(out)
}
